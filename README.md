## 🚀 Featured Projects

### [Multi-Document Research Assistant (Agentic RAG)](https://github.com/omairtahir3/multi_doc_research_assistant)
Engineered an end-to-end agentic RAG platform orchestrating a multi-agent team (*Planner, Retriever, Synthesizer*) via **LangGraph** and **Groq LPU** (Llama 3.3 70B). Integrated **PyMuPDF** vector ingestion reducing document parsing latency by **85%** into **ChromaDB**, backed by a **FastAPI** backend and **Next.js 16 (React 19)** frontend with real-time answer synthesis and citation attribution.  
*Tech: LangGraph, Groq LPU, FastAPI, PyMuPDF, ChromaDB, SentenceTransformers, Next.js 16, React 19*

### [LOCUS: AI-Powered Medication Compliance Platform](#)
Engineered an end-to-end distributed system for elderly medication compliance verification. Built a **React/Node.js** web dashboard integrated with a **Python/FastAPI** computer vision backend. Utilized **MediaMTX** for real-time RTMP streaming and a multi-threaded architecture with **OpenCV & YOLO** to verify prescription intake in real-time.  
*Tech: React, Node.js, FastAPI, OpenCV, YOLO, MediaMTX, WebSockets* 

### [Battlefield Surveillance System](#)
Built a real-time defense surveillance system to detect and localize military assets from drone and satellite feeds. Integrated **YOLOv11** achieving **93.6% mAP@50** and optimized inference via **ONNX Runtime**. Dynamically transformed bounding-box pixel telemetry to precise GPS coordinates with an interactive **Leaflet.js** map in under **4 seconds**.  
*Tech: Python, FastAPI, YOLOv11, ONNX Runtime, OpenCV, Leaflet.js* 

### [Mammography Diagnostic Pipeline (VinDr-Mammo)](#)
Developed a two-stage breast cancer classification pipeline using the VinDr-Mammography dataset. Evaluated multiple CNN and Transformer architectures, finalizing **DenseNet121** with comprehensive data augmentation and class-balanced focal loss. Applied **INT8 quantization**, cutting inference latency by **35%** for clinical diagnostic workflows.  
*Tech: Python, PyTorch, DenseNet121, Computer Vision, Model Quantization*
