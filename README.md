### [LOCUS: AI-Powered Medication Tracking Platform](#)
Engineered an end-to-end distributed system for elderly medication compliance. Built a React/Node.js web dashboard integrated with a Python/FastAPI computer vision backend. Utilized MediaMTX for real-time RTMP streaming and a multi-threaded architecture to verify medication intake.  
*Tech: React, Node.js, FastAPI, OpenCV, YOLO, MediaMTX* 

### [Mammography Classification System](#)
Developed a two-stage breast cancer classification pipeline using the VinDr-Mammography dataset. Evaluated multiple CNN and Transformer architectures, finalizing DenseNet121 with comprehensive data augmentation and class-balanced loss functions.  
*Tech: Python, PyTorch, Deep Learning, Computer Vision*  

### [Multi-Document Research Assistant (RAG)](#)
Engineered a production Retrieval-Augmented Generation (RAG) pipeline indexing over 10,000 PDFs with sentence-transformer embeddings. Developed a high-performance backend achieving 87% answer correctness with sub-500ms latency.  
*Tech: Python, FastAPI, NLP, Transformers, Vector Databases* 

### [Battlefield Surveillance System](#)
Built a real-time surveillance system to detect military assets. Processed over 1,000 drone and satellite images, dynamically converting object detections to precise GPS coordinates with a 4-second end-to-end latency.  
*Tech: Python, FastAPI, YOLOv8, OpenCV, ONNX Runtime, Leaflet.js*
